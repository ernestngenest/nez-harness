# Skill Catalog

Use [references/categories.md](references/categories.md) as the authoritative category index.

When recommending skills:

1. Match the request to the closest primary category.
2. Read the descriptions of likely skills before selecting one.
3. Mention adjacent skills only when they materially help the request.
4. Treat categories as navigation labels, not invocation rules.
